# ADAL PRICE — сайт оценочной компании

Одностраничный сайт (лендинг) для оценочной компании ADAL PRICE, Астана.
Чистый HTML/CSS/JS без сборки: можно открыть `index.html` в браузере или выложить папку на любой статический хостинг.

## Структура
```
adal-price/
├── index.html          — вся страница
├── assets/styles.css   — стили (цвета бренда в начале файла, :root)
├── assets/main.js      — меню, заявка → WhatsApp, анимации
├── assets/img/         — логотип, фото, иконки сайта
├── admin.html          — кабинет для благодарственных писем (/admin)
├── assets/admin.js     — логика кабинета: вход, загрузка, удаление, смена пароля
├── _headers            — заголовки безопасности (их читает и Cloudflare Pages, и наш Worker)
├── robots.txt
└── deploy/             — Worker: упаковка сайта (build-worker.mjs) и API писем (api.mjs)
```

## Калькулятор квартиры
Считает примерный диапазон цены квартиры на вторичном рынке Астаны и после расчёта даёт кнопку «Заказать точную оценку» (WhatsApp с параметрами). Кнопки перехода на Krisha.kz нет (убрана по просьбе клиента); осталась только ссылка-источник в подписи под калькулятором.

- **Уровень рынка** — средняя цена предложения квартир в Астане с Krisha.kz: 617 300 ₸/м² на 18.11.2026.
  Хранится в двух местах `index.html`, рядом: атрибут `data-avg` у формы `#calc-form` и текст в `.calc__source` (число и дата).
  Где смотреть свежее значение: еженедельные данные Krisha по городам (`https://krisha.kz/analytics/`, город «Астана», поле `avg`) или их ежемесячные статьи о ценах. Обновлять раз в месяц вручную.
- **Поправки** (район, комнатность, год постройки, ремонт, класс жилья, этаж) и разброс диапазона (Есиль ±15%, остальные ±8%) взяты из версии сайта, которую прислал клиент; они в `assets/main.js` (объекты `DISTRICT`, `ROOMS`, `YEAR`, `CONDITION`, `TIER`, `FLOOR`).
- **Почему не автоматически.** Пользовательское соглашение Krisha.kz запрещает без письменного разрешения Kolesa заходить на сайт программами и извлекать с него информацию. Цитировать их информационные материалы можно только с активной ссылкой на Krisha.kz — она есть под калькулятором. Для автоматического обновления нужно письменное разрешение Kolesa Group.

## Кабинет: благодарственные письма
Адрес: `<сайт>/admin` (на временном адресе — https://adal-price.imakanovr.workers.dev/admin).

- Вход по одному паролю. Стартовый пароль передаётся клиенту лично (в репозитории его нет); клиент меняет его в кабинете — после этого прежний пароль не работает, а другие устройства выходят из кабинета.
- «Добавить письмо»: PDF или фото (JPG, PNG, WebP) + «От кого» и дата. Всё превращается в картинки прямо в браузере, до отправки:
  фото — в одну страницу; PDF — каждая страница отрисовывается библиотекой PDF.js (до 10 страниц; длинная сторона 2000 px, при 4+ страницах 1600 px), плюс миниатюра 600 px. Сам PDF на сайт не попадает.
  Сразу после выбора файла кабинет показывает, как письмо будет выглядеть, и сколько в нём страниц. PDF с паролем или повреждённый — понятная ошибка.
- Письма сразу появляются на сайте в блоке «О компании»; по нажатию открываются крупно: кнопка «Увеличить» (или клик по письму) — размер для чтения, стрелки и ←/→ листают страницы, затем следующее письмо; Esc закрывает. На карточке многостраничного письма — значок «N стр.». Можно удалить. Предел — 100 писем, до 10 МБ на письмо.
- PDF.js 4.10.38 (legacy-сборка, работает и в старых браузерах) не хранится в репозитории: Worker берёт файлы с jsDelivr (запасной — unpkg) и отдаёт их с адреса сайта `/assets/vendor/pdfjs-4.10.38/…` только если SHA-256 совпадает с записанным в `deploy/build-worker.mjs`. Поэтому CSP остаётся строгой (скрипты только с самого сайта); кабинету дополнительно разрешён `'wasm-unsafe-eval'` — PDF.js декодирует сканы в JPEG 2000 через WebAssembly. Если CDN недоступен, фото загружаются как обычно, а для PDF кабинет попросит повторить позже.
- Хранение: Durable Object `LettersStore` (SQLite) того же Worker — без отдельной базы и бесплатно на тарифе Workers Free.
- Если пароль забыли: Cloudflare → Workers → adal-price → Settings → Variables and Secrets → добавить секрет `ADMIN_RESET` с новым паролем (от 10 символов), войти с ним в кабинет, сменить пароль и удалить секрет.
- Новая установка: секрет `ADMIN_BOOTSTRAP` — первый пароль, работает, пока пароль ещё не сохранён (`npx wrangler secret put ADMIN_BOOTSTRAP -c deploy/wrangler.jsonc`). Для локального запуска — файл `deploy/.dev.vars` (в git не попадает).
- Защита: сессия в cookie `HttpOnly; Secure; SameSite=Strict`, подписана HMAC; изменения принимаются только с самого сайта (проверка Origin); пароль хранится как HMAC-SHA256 с солью; после неверного пароля — пауза 1 с; принимаются только настоящие JPEG (проверка сигнатуры файла, размеры страниц и их число проверяются), подписи выводятся как текст.
- При переносе сайта в аккаунт клиента письма сами не переедут — их нужно будет добавить заново (или перенести вместе с Worker).

## Безопасность
- `_headers`: политика CSP (скрипты только с самого сайта, шрифты Google, карта Google), запрет встраивать сайт в чужие страницы, HSTS, nosniff, Referrer-Policy, Permissions-Policy.
- Наружу отдаются только страница и используемые ею файлы; README, `_headers`, `deploy/` не видны.
- Форма заявки ничего не хранит и не отправляет на сервер — только открывает WhatsApp. Сервер есть только у кабинета писем (см. выше).
- Нет сторонних скриптов на страницах: Google Fonts и карта Google — единственные внешние ресурсы. PDF.js кабинета отдаётся с адреса сайта после проверки SHA-256 (см. «Кабинет»).

## Публикация (Cloudflare Workers)
Сайт опубликован как Cloudflare Worker `adal-price`: https://adal-price.imakanovr.workers.dev

Весь сайт упаковывается в один скрипт (тексты — внутри, картинки — бинарными модулями, заголовки — из `_headers`):
```bash
cd adal-price
node deploy/build-worker.mjs                       # собирает deploy/.build/worker.mjs
npx wrangler@4.156.0 deploy -c deploy/wrangler.jsonc
```
На адресе `*.workers.dev` страница помечена `X-Robots-Tag: noindex`, чтобы предпросмотр не попал в поиск.
На своём домене (подключается в Cloudflare → Workers → adal-price → Domains) индексация работает обычным образом.

Нагрузка: бесплатный тариф Workers — 100 000 запросов в день на аккаунт (одно первое посещение ≈ 7–8 запросов), без ограничения в секунду.
При переносе к клиенту на Cloudflare Pages (загрузить `index.html`, `assets/`, `_headers`, `robots.txt`) запросы к статичным файлам бесплатные и без лимита.

## Что уточнить перед запуском
- Промокоды SOCIAL10 и REALTY10: если акция закончится — удалить блок `<section class="promo">`, плашку `promo-pill` в первом экране и поле «Промокод» в форме.
- Калькулятор: поправки взяты из файла клиента — пусть подтвердит их; цену Krisha обновлять раз в месяц.
- Домен: после выбора добавить `<link rel="canonical">` и `og:image` с полным адресом.
- Цены и сроки — добавить, если нужно показывать на сайте.
