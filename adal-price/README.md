# ADAL PRICE — сайт оценочной компании

Одностраничный сайт (лендинг) для оценочной компании ADAL PRICE, Астана.
Чистый HTML/CSS/JS без сборки: можно открыть `index.html` в браузере или выложить папку на любой статический хостинг.

## Структура
```
adal-price/
├── index.html          — вся страница
├── assets/styles.css   — стили (цвета бренда в начале файла, :root)
├── assets/main.js      — меню, заявка → WhatsApp, анимации
└── assets/img/         — логотип, фото, иконки сайта
```

## Блоки страницы
1. Шапка: логотип, меню, телефон, кнопка WhatsApp.
2. Первый экран: «Оценка недвижимости, бизнеса и имущества в Астане», слоган «Точная оценка — уверенные решения!», плашка акции −10%.
3. Услуги — три направления, как в профиле Instagram и закреплённом посте:
   недвижимость (квартиры, дома и дачи, гаражи, помещения/здания/сооружения, земля, незавершённое строительство),
   бизнес и активы (доли ТОО и акции АО, имущественные комплексы, основные средства, интеллектуальная собственность, нематериальные активы),
   имущество (транспорт, оборудование, офисная мебель, техника).
4. Для чего: для банка, суда, инвестора; когда оценка нужна бизнесу.
5. Акция: −10% на оценку для кредитования, промокод CREDIT10% (кнопка копирует код).
6. Как проходит оценка: 4 шага.
7. Документы: вкладки «Квартира, дом, помещение» и «Для Отбасы банка», где взять справку (ЦОН, eGov, Kaspi/Halyk), как сфотографировать документы.
8. О компании: «Кто мы?», экспертность, точность, партнёр; блок «Адал» с текстом «Почему важна объективность».
9. Что влияет на стоимость.
10. Заявка: форма собирает сообщение (с промокодом по галочке) и открывает WhatsApp — сервер не нужен.
11. Контакты: адрес, график, телефон, Instagram, карта.
12. На телефоне снизу закреплены кнопки «Позвонить» и «WhatsApp».

Тексты взяты из публикаций @adal__price. У каждой кнопки WhatsApp свой готовый текст сообщения — атрибут `data-wa` в `index.html`.

## Публикация (Cloudflare Workers)
Сайт опубликован как Cloudflare Worker `adal-price`: https://adal-price.imakanovr.workers.dev

Весь сайт упаковывается в один скрипт, поэтому отдельная загрузка статических файлов не нужна:
```bash
cd adal-price
node deploy/build-worker.mjs                       # собирает deploy/.build/worker.mjs
npx wrangler@4.156.0 deploy -c deploy/wrangler.jsonc
```
На адресе `*.workers.dev` страница помечена `X-Robots-Tag: noindex`, чтобы предпросмотр не попал в поиск.
На своём домене (подключается в Cloudflare → Workers → adal-price → Domains) индексация работает обычным образом.

## Что уточнить перед запуском
- Акция CREDIT10%: если закончится — удалить блок `<section class="promo">`, плашку `promo-pill` в первом экране и галочку в форме.
- Домен: после выбора добавить `<link rel="canonical">` и `og:image` с полным адресом.
- Цены и сроки — добавить, если нужно показывать на сайте.
