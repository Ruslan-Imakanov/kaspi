# ADAL PRICE — сайт оценочной компании

Одностраничный сайт (лендинг) для оценочной компании ADAL PRICE, Астана.
Чистый HTML/CSS/JS без сборки: можно открыть `index.html` в браузере или выложить папку на любой статический хостинг.

## Структура
```
adal-price/
├── index.html          — вся страница
├── assets/styles.css   — стили (цвета бренда в начале файла, :root)
├── assets/main.js      — меню, заявка → WhatsApp, анимации
└── assets/img/         — логотип, фото, иконки сайта
```

## Блоки страницы
1. Шапка: логотип, меню, телефон, кнопка WhatsApp.
2. Первый экран: «Оценка недвижимости и имущества в Астане», слоган «Точная оценка — уверенные решения!».
3. Что оцениваем: квартиры, частные дома, земельные участки, коммерческая недвижимость; оборудование, офисная мебель, компьютеры и техника, транспорт.
4. Для чего: для банка, для суда, для инвестора; когда оценка нужна бизнесу.
5. Как проходит оценка: 4 шага.
6. Что влияет на стоимость + блок «Адал — честный».
7. Заявка: форма собирает сообщение и открывает WhatsApp (сервер не нужен).
8. Контакты: адрес, график, телефон, Instagram, карта.
9. На телефоне снизу закреплены кнопки «Позвонить» и «WhatsApp».
